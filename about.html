I didn't get into software engineering to build todo apps. I got into it to build systems that solve actual problems.

The software bug bit early — I just had no idea where to start. So I did the next best thing and spent years buried in graphics and editing, scratching the creative itch while the engineering dream sat on the shelf. Then the Java Institute for Advanced Technology gave me a way in, and the coding journey finally began in earnest.

Today I'm a software engineering undergraduate pursuing a BSc (Hons) in Software Engineering from Birmingham City University via the Java Institute (2023–2027). Since November 2025 I've been an Intern Software Engineer at Innobot Health — Python automations and RPA for US healthcare operations.

My engineering work is backend-first: architecture, data flows, APIs, and systems that hold up under real users. I've built a connected SaaS ecosystem solo — a multi-tenant client-ops platform (Atlas), an LMS control plane with Ed25519 licensing (Sentinel), and a white-label LMS — alongside client work like PJBiology LMS (5,000+ students) and LeisureLand reservations.

I'm also a software engineer at Dessina.co (Feb 2025–present), building web and desktop solutions with Java, PHP, and MySQL.

02 / Philosophy

HOW ITHINK

01

ARCHITECTURE FIRST

Before I write a line of code, I understand the shape of the problem. What data flows where. What breaks under load. What the system needs to be 6 months later.

02

OWN THE LIFECYCLE

I've shipped systems from a blank file to production. That full-cycle ownership changes how you code — because you know you'll be the one maintaining it.

03

AUTOMATE OR DIE

If a human is doing something a script could do, that's a problem I need to solve. My internship work has reinforced this — automation is engineering empathy at scale.
